什么是16种性格类型？

AI性格类型测试是AI Test Lab基于瑞士心理学家卡尔·荣格（Carl Jung）的心理类型理论独立开发的工具。它通过四个心理轴分析您的性格，判断您最接近16种类型中的哪一种。虽然与Myers-Briggs Type Indicator®（MBTI®）使用相似的框架，但本测试与MBTI®无关联。

四个心理轴

E / I
外向 vs 内向

衡量您是从社交互动中获得能量（E），还是从独处时间中恢复精力（I）。

S / N
感觉 vs 直觉

衡量您是通过具体事实处理信息（S），还是通过模式和可能性解读信息（N）。

T / F
思考 vs 情感

衡量您是通过逻辑分析做决定（T），还是优先考虑价值观和情感（F）。

J / P
判断 vs 感知

衡量您是偏好有计划、有组织的生活方式（J），还是偏好灵活、随机应变的方式（P）。

常见问题

这个测试和MBTI一样吗？ +

不一样。本测试由AI Test Lab基于荣格心理类型理论独立开发。Myers-Briggs Type Indicator®（MBTI®）是Myers-Briggs Company的注册商标，本测试与其无任何关联。

测试结果有多准确？ +

本测试以娱乐和自我了解为目的。虽然基于荣格理论，但不能替代专业的心理评估。请将结果作为自我探索的参考。

16种类型是如何确定的？ +

通过组合四个轴（E/I、S/N、T/F、J/P）中得分较高的字母来确定类型。例如，E、N、T、J得分较高则为ENTJ。4×4=16种可能的组合。
