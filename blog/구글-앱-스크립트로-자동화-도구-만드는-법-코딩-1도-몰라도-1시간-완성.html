핵심 요약: 구글 앱 스크립트(Google Apps Script)는 코딩 경험 없이도 구글 스프레드시트, 지메일, 구글 폼을 자동화할 수 있는 가장 쉬운 방법입니다. 실제로 만든 "매월 청구서 자동 발송" 스크립트를 단계별로 설명합니다.

구글 앱 스크립트란?

구글 스프레드시트 안에 내장된 프로그래밍 도구입니다. JavaScript 기반이라 별도 프로그램 설치 없이 브라우저에서 바로 작성하고 실행할 수 있습니다. 가장 큰 장점은 구글의 모든 서비스와 바로 연동된다는 것입니다.

실습: 이메일 자동 발송 만들기

매월 고객 목록에서 개별 이메일을 보내는 작업을 자동화한 사례입니다.

1단계: Apps Script 열기

구글 스프레드시트 열기 → 상단 메뉴 확장 프로그램 → Apps Script 클릭

2단계: 코드 입력

function sendInvoices() {
  var sheet = SpreadsheetApp.getActiveSheet();
  var data = sheet.getDataRange().getValues();
  
  for (var i = 1; i < data.length; i++) {
    var name = data[i][0];    // A열: 이름
    var email = data[i][1];   // B열: 이메일
    var amount = data[i][2];  // C열: 청구금액
    
    GmailApp.sendEmail(
      email,
      "[청구서] " + name + "님의 이번 달 청구서",
      name + "님, 이번 달 청구 금액은 " + amount + "원입니다."
    );
    
    sheet.getRange(i + 1, 4).setValue("발송완료");
  }
  
  SpreadsheetApp.getUi().alert("모든 청구서 발송 완료!");
}

3단계: 저장 후 실행

저장(Ctrl+S) → 실행 버튼(▶) → 구글 계정 권한 허용 → 완료

결과: 스프레드시트에 있는 100명에게 30초 만에 개인화된 청구서 이메일 발송 완료. 수동으로 했을 때 2~3시간 걸리던 작업입니다.
